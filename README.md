Павлюченко Елизавета Александровна, Б9124-09.03.03пикд(4)
Читательский дневник-трекер
Приложение выводит список книг (название, автор, год, жанр и статус).
Есть возможность изменить статус книги на следующий,
удиветь статистику (количество всех, планируемых, читаемых и прочитанных книг),
найти книги по названию и/или применив фильтры.
